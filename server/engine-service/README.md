# Сервис конфигуратора лекал

Считает чертёж-образец на сервере: построения (скрипты) покупателю не отдаются, наружу уходят только поля формы и картинка с водяным знаком.

- `POST /api/preview` `{ "model": "<код модели>", "selection": {…} }` → поля формы + картинка (PNG, если установлен `@resvg/resvg-js`, иначе SVG).
- Модели лежат файлами `/var/lib/stroykroy/models/<код>.json`; их пишет импорт каталога в Drupal.
- Слушает только `127.0.0.1:3100`; снаружи открывается nginx по адресу `/sk-api/`.
- Проверка ядра: `node src/test.mjs /путь/к/файлу.ALG`.

Файлы для запуска — в `deploy/` (systemd и фрагмент nginx).

## Самопроверка алгоритмов

Прогон моделей каталога по базе типовых размеров ОСТ (147 фигур), с вариантами опций и элементами (рукав и т. п.):

- на сайте: Администрирование → Конфигурация → «Проверка алгоритмов» (`/admin/commerce/stroykroy-selftest`);
- на сервере: `node src/selftest.mjs [код_модели] [--full] [--out отчёт.txt]`;
- HTTP (только с самого сервера): `POST /api/selftest {"model":"…","mode":"quick|full","mail":true}`.

Одинаковые ошибки сводятся в группу: текст ошибки со строкой скрипта, размеры и варианты, где она случилась, и готовый блок «мерки rz_N + опции par_N + ease_*» для вставки в начало алгоритма в VS Code. Тот же блок стоит вверху письма об ошибке построения.
