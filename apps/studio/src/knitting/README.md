# Вкладка «Вязание» (этап 1 + операции + AYAB)

Плотность → петли и ряды по контурам деталей → проверка по игольнице →
список «ряд / петли / операция / Δ» с галочками для бумажки и печати на A4.
Рассчитано на Brother KH910 (200 игл, 4,5 мм) + KR850 + AYAB, но от машины
зависит только число игл.

## Как пользоваться

1. Открыть построение в студии (для первой работы — `PDK10001`).
2. Вкладка **«Вязание»**.
3. Ввести плотность по образцу: петли и ряды на 10 см, число игл в работе (200).
4. Выбрать деталь. Для половинки по сгибу включена галочка
   **«Деталь на половину (по сгибу)»** — ширина удваивается зеркально.
5. **«Изменения» / «Все ряды»** — только строки с +/− или каждый ряд подряд.
6. **Галочки** отмечают связанные ряды; они сохраняются в браузере.
7. В колонке **«Операция»** — предложение: «убавить», «закрыть», «центр»,
   «прибавить», «частичное». Галочка **«Плечо — частичным вязанием»** ставит
   «частичное» для рядов после горловины; любую операцию можно поменять вручную.
8. **«На весь экран»** — схема и таблица; **«Печать»** — выбранная деталь,
   **«Печать всех»** — весь комплект, каждая деталь с новой страницы.

## Что считается

- контур `Piece.outline` в сантиметрах, без припусков на швы;
- каждый ряд — по середине высоты ряда, ширина в петлях;
- в режиме «Изменения» — только ряды, где число петель меняется (плюс первый);
- Δ — изменение на всю ширину; при работе с двух сторон делится на 2
  (центр горловины не делится);
- «закрыть» предлагается для крупных изменений (≥ 8 петель): горловина,
  плечо, подмышка; «убавить»/«прибавить» — для мелких;
- «центр» определяется по отходу кромки от линии сгиба (спинка, капюшон) или
  по падению ширины при неподвижных внешних кромках (полочка);
- «частичное» ставится галочкой для плеча после горловины (выдвижение игл);
- игольница — максимальная ширина в петлях ≤ числа игл;
- линия сгиба — длинная вертикальная кромка у левой или правой границы детали;
- печатный лист A4: три узкие колонки по 70 строк (210 на страницу),
  в каждой — «ряд / петли / операция / Δ», галочки и подпись.

## Рисунок AYAB

- PNG шириной до 200 px, 1 px = 1 петля, 1 ряд = 1 ряд;
- загружается для выбранной детали и хранится в браузере;
- накладывается на схему детали (кнопка «Скрыть/Показать на схеме»),
  повторяется по ширине детали;
- **«Скачать PNG»** собирает 1-битный ч/б PNG шириной в максимум петель
  детали и высотой в ряды — файл можно открыть в AYAB Studio;
- если деталь шире 200 игл, выгрузка блокируется с объяснением;
- рисунок не отправляется в AYAB автоматически — только файл.

## Ограничения текущей версии

- операция — предложение, а не готовый расчёт частичного вязания;
  «закрыть»/«убавить»/«частичное» пользователь может поправить в таблице;
- нет прямого обмена с AYAB — только импорт/экспорт PNG;
- ориентация рисунка (верх/низ) не переворачивается автоматически —
  проверьте в AYAB Studio;
- нет размерной линейки — этап 4;
- «по сгибу» определяется по имени детали, галочку можно переключить вручную.

## Файлы

- `engine.ts` — расчёт, без React;
- `KnittingTab.tsx` — интерфейс и печатные листы;
- `knitting.css` — стили (префикс `.kn`).

## Проверка на PDK10001 (28 п. × 40 р. на 10 см)

| Деталь | Рядов | Макс. петель | Ширина |
|---|---:|---:|---:|
| Спинка (по сгибу) | 314 | 191 | 68,0 см |
| Полочка | 312 | 90 | 32,2 см |
| Рукав | 233 | 140 | 50,0 см |
| Капюшон (по сгибу) | 172 | 152 | 54,1 см |

Спинка: 191 петля в первом ряду, подмышка на 185-м (−13, «закрыть»),
горловина/плечо на 301-м (−40, «закрыть»). Все четыре детали влезают в 200 игл.

Печать: выбранная спинка целиком — 2 страницы, весь комплект — 7 страниц
(при режиме «Все ряды», три колонки на A4). Деталь на 208 рядов помещается
на одну страницу.
